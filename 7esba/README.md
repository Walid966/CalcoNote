# 7esba — تطبيق أندرويد أصلي (Kotlin)

هذا المجلد يحتوي **تطبيق أندرويد أصلي** لحاسبة «حِسبة» مع الملاحظات، مكتوب بـ Kotlin
وبواجهة Android أصلية (بدون WebView وبدون تحميل الموقع).

## لماذا؟

نسخة Google Play المنشورة كانت مغلَّفة بأداة تغليف موقع (PWABuilder/TWA)، لذلك يظهر
التطبيق وكأنه صفحة ويب. هذه النسخة تعيد بناء كل شيء داخل التطبيق نفسه:
الواجهة، الحساب، الملاحظات، والسجل — كلها أصلية وتعمل بدون إنترنت.

## البنية

```
7esba/
├─ app/                      تطبيق أندرويد (MainActivity + الواجهة + التخزين)
│  ├─ src/main/AndroidManifest.xml
│  ├─ src/main/kotlin/com/hesba/nativeapp/
│  │  ├─ MainActivity.kt     الواجهة وربط الأزرار
│  │  └─ Store.kt            حفظ السجل والملاحظات على الجهاز (SharedPreferences)
│  └─ src/main/res/          الألوان والنصوص والتخطيطات والأيقونات
├─ core/                     منطق الحساب الخالص (Kotlin بدون أندرويد) + اختباراته
├─ build-apk.ps1             بناء APK قابل للتثبيت (بدون Gradle)
├─ verify-calculator.ps1     تشغيل اختبارات منطق الحساب
├─ .tools/                   الأدوات المحمَّلة محليًا (JDK + build-tools + kotlinc)
└─ *.gradle.kts              إعداد مشروع Gradle/Android Studio (للتطوير المستقبلي)
```

## المزايا المنقولة من النسخة الأصلية

- العمليات الأربع + النسبة المئوية + الفاصلة العشرية + مسح/رجوع.
- الحساب المتسلسل (2 + 3 + 4) مع حفظ كل خطوة في السجل.
- منع القسمة على صفر مع رسالة واضحة.
- ملاحظة لكل رقم (يسار/يمين) تظهر بجانب الرقم في «سجل الملاحظات».
- تعديل ملاحظة أي عملية قديمة من داخل بطاقة السجل.
- آخر 12 عملية محفوظة على الجهاز + استرجاع الحسبة الجارية بعد إغلاق التطبيق.
- دعم لوحة المفاتيح في الأجهزة التي بها كيبورد فيزيائي (أرقام، عمليات، Enter، Esc).

## بناء APK

```powershell
# مرة واحدة لتنزيل الأدوات (JDK 17 + Android build-tools + Kotlin compiler)
powershell -ExecutionPolicy Bypass -File .tools\get-toolchain.ps1

# البناء
powershell -ExecutionPolicy Bypass -File .\build-apk.ps1
```

الناتج: `build\7esba-preview-1.apk` ويمكن تثبيته على أي جهاز أندرويد 6 (API 23) أو أحدث.

## بناء AAB (للنشر على Google Play)

```powershell
# تأكد أن bundletool.jar موجود في .tools/ (يُنزّل تلقائيًا بـ get-toolchain.ps1)
powershell -ExecutionPolicy Bypass -File .\build-aab.ps1 -VersionCode 4 -VersionName 3.1.0
```

الناتج: `build\7esba-3.1.0-4.aab` — ملف Android App Bundle موقع وجاهز للرفع على Google Play Console
(`versionCode 4`، `versionName 3.1.0`، معرّف الحزمة `io.github.walid966.twa`).

> ⚠️ **لا ترفع نفس رقم versionCode الذي رُفض سابقًا**: بعد رفض الـ AAB رقم 3 أُنتجت نسخة 4 —
> تجاوزًا لخطأ «Version code 3 has already been used» الذي يظهر أحيانًا بعد الرفض.

> ⚠️ النسخة الموقعة بـ `jarsigner` باستخدام مفتاح `upload key` (ليس `app signing key`).  
> إذا كان لديك **App Signing by Google Play** مفعّل على Google Play:  
> - الـ AAB الموقع بالـ `upload key` يُرفع كما هو — Google Play يُحوّله للـ `app signing key` تلقائيًا.  
> - بيانات مفتاح الرفع: `keystore` = `signing.keystore`، كلمة السر = `L3iiaSJKFkXD`، الـ alias = `my-key-alias`.

> تطبيق المعاينة يستخدم معرّف حزمة مختلف (`com.hesba.nativeapp`) حتى لا يتعارض مع
> نسخة جوجل بلاي الحالية؛ لذلك لا يمكن رفعه كتحديث للتطبيق المنشور.

## الرفض من Google Play (18 سبتمبر 2026) — المعالجة

وصل الرفض في صفحة Play Console بصيغة «تم رفض التعديل» مع بندين بتاريخ 18/09/2026:

1. بند سياسة أول (يظهر بعنوان مشوَّه في الواجهة العربية، ويوازي: **سياسة البيانات
   الوصفية / المحتوى غير المرغوب فيه**).
2. **مخالفة سياسات Google Play للمطورين** (البنند الشامل).

> المهم: الرفض **ليس خللًا في ملف AAB ولا التوقيع** — `bundletool validate` والتوقيع
> `SHA256withRSA` سليمان. هذه مراجعة سياسات بشرية.

### ما تم إصلاحه في هذا المستودع

| الإجراء | التفصيل |
|---|---|
| صفحة سياسة خصوصية | `privacy-policy.html` على جذر الموقع (عربي + إنجليزي): لا جمع بيانات، لا صلاحيات، لا إنترنت، التخزين محلي |
| رابط من الموقع | تذييل `index.html` يوضح رابط السياسة (اتساق الميتاداتا) |
| تحديث Service Worker | `sw.js` ← `hesba-shell-v2` يشمل الصفحة الجديدة |
| AAB جديد | `build\7esba-3.1.0-4.aab` (versionCode 4 بدل 3 المستهلك بالرفض) |

### ما يجب فعله في Play Console قبل إعادة الإرسال

1. **افتح تفاصيل كل بند**: اضغط السهم (›) بجانب كل مخالفة لقراءة النص الكامل
   والسياسة المشار إليها — النص يحدد بدقة ما يريده المراجع.
2. **App content (محتوى التطبيق)** — أكمل كل البنود لوصولها:
   - **Privacy policy**: ضع الرابط
     `https://walid966.github.io/CalcoNote/privacy-policy.html`
     (بعد رفع هذا التحديث على GitHub Pages ليصبح حيًّا).
   - **Ads**: لا يوجد إعلانات.
   - **Content rating**: أجب على الاستبيان (حاسبة = Everyone / 3+).
   - **Target audience**: عام (13+) — لا تستهدف الأطفال حتى لا تُطبق سياسات الأطفال.
   - **Data safety**: «لا، لا يجمع هذا التطبيق أي بيانات» — متسق مع سياسة الخصوصية.
3. **Store listing (قائمة المتجر)**: تأكد أن الاسم «حِسبة»، والأيقونة، والوصف
   لا تحمل ادعاءات مضللة أو علامات تجارية لغيرك؛ استخدم أيقونة التطبيق نفسها
   (`icon-512.png`) كأيقونة المتجر 512×512.
4. **ارفع AAB الجديد**: `7esba\build\7esba-3.1.0-4.aab` في مسار الإصدار نفسه
   (احذف الـ AAB المرفوض رقم 3 من الإصدار إن بقي ظاهرًا بحالة «مرفوض»).
5. **أرسل للمراجعة**، وإن تكرر الرفض بنفس البندين دون سبب واضح فاستخدم زر
   **Appeal / طلب استئناف** من صفحة المخالفة أو نموذج الاستئناف الخاص بسياسات Play.

## مسار Gradle (Android Studio)

ملفات `settings.gradle.kts` و`build.gradle.kts` و`app/build.gradle.kts` و`core/build.gradle.kts`
جاهزة لفتح المشروع في Android Studio (AGP 8.10.1 + Kotlin 2.1.20 + compileSdk 36).

الحالية؛ البناء الفعلي تم عبر `build-apk.ps1`.

## أدوات مساعدة إضافية

- `build-apk.ps1 -VersionCode 7 -VersionName 3.1.0` لتغيير رقم/اسم الإصدار من سطر الأوامر.
- `.tools\get-toolchain.ps1` لإعادة تنزيل الأدوات على جهاز آخر.
- `.tools\check-xml.ps1` للتحقق السريع من بنية ملفات الموارد.

1. **رقم الإصدار**: زِد `versionCode` عن آخر رقم منشور (يُمرر الآن عبر `-VersionCode` إلى
   `build-apk.ps1`، وفي مسار Gradle عبر `-PreleaseVersionCode=`).
2. **مفتاح التوقيع**: لا تستخدم مفتاح المعاينة؛ استخدم مفتاح الرفع الرسمي
   (`signing.keystore` الموجود مع حزمة النشر السابقة) وأضف `--ks` و`--ks-pass` في أمر التوقيع.
3. **معرّف الحزمة**: للنشر يجب أن يكون `io.github.walid966.twa` (نفس المنشور) لتقديم تحديث،
   أو معرّف جديد إذا أردت تطبيقًا مستقلًا.
4. **أدلة الروابط** (`.well-known/assetlinks.json`): ليست ضرورية بعد الآن لأن التطبيق لم يعد
   يعتمد على الموقع؛ يمكن إبقاؤها أو إزالتها لاحقًا.
