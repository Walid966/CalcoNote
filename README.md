# حِسبة

آلة حاسبة عربية بسيطة تحفظ ملاحظة مرتبطة بكل رقم داخل العملية.

## التشغيل

لا تحتاج إلى تثبيت أي شيء. افتح `index.html` مباشرة في المتصفح.

## النشر على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub.
2. ارفع الملفات الموجودة في هذا المجلد إلى المستودع.
3. من **Settings > Pages** اختر **Deploy from a branch**.
4. اختر فرع `main` ومجلد `/ (root)` ثم اضغط **Save**.

بعدها سيعمل الموقع كرابط GitHub Pages. الملاحظات والعمليات تُحفظ محليًا في متصفح كل مستخدم، ولا يتم إرسالها إلى أي خادم.
